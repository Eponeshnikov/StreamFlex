# Измеренные радиоканалы

## Комната 1405

| Папка под `indoor/room_1405/` | Серия |
| --- | --- |
| `cross/raw/` | Четыре креста 12 ноября, 2–3 и 5,3–6,3 ГГц, с экраном и без экрана. |
| `cross/calibration/` | Кабельные измерения для калибровки. |
| `gscan/` | Г‑скан 13 ноября, 2,5 ГГц. |
| `grid/rearrangement_2026-11/` | Шесть сканов сетки после перестановки, 16–19 ноября. |
| `grid/archive_42x40/` | Сетки 42×40, январские S21 и июльские дуплексные S21/S12, 2026. |
| `power_sweep_3x3/` | Июльский свип мощности на сетке 3×3. |

Локальный `catalog.json` хранит идентификаторы измерений, имена источников и SHA‑256. У первых сеток прежние имена файлов работают через ссылки из `output_data/experiment_ir/`. Это сохраняет ссылки старых снимков и идентификаторы в ключах кэша. Копии новых измерений из Public имеют собственные inode.

## Городские измерения

- `outdoor/wiworld/` хранит исходные CIR, метаданные, положение передатчиков, выравнивание маршрутов и выборки. Связанная сцена покрывает маршрут BUPT для 3,7 ГГц.
- `outdoor/niigata/` хранит измерения Niigata, метаданные и выгрузки.

Загрузчики WiWorld и Niigata используют папки в `outdoor/`. При чтении старых индексов WiWorld пути к MAT восстанавливаются относительно текущей папки `unpacked/`. Связи между измерениями и моделями описаны в [каталоге сцен](../sionna-scenes/README.md). Формат загрузки и чтения описан в [Pages](../pages/datasets/tools/README.md).

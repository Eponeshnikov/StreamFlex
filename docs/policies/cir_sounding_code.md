# Выбор кода зондирования CIR

Решение пользователя от 17.11.2026: для новых собственных измерений и моделирования CIR основной код — **M-последовательность**. Это заменяет Gold как неявный default, в том числе в городских и комнатных исследованиях. Измеренные VNA S-параметры остаются измеренными S-параметрами: код к ним не добавляется.

- IQ Generator: по умолчанию `M-Sequence`, если она доступна; иначе пустой выбор, без автоматического перехода к Gold. Сначала сгенерировать/загрузить M. Сохранённые явные widget/snapshot-настройки не переписываются.
- В новом headless-запуске явно выбирать генератор M и IQ source `M-Sequence`; у исследовательского city runner явно указывать `--code mseq`, даже если его исторический default — Gold.
- Для текущего городского сравнения базовые параметры: степень 11, 2047 чипов, полином `x^11+x^2+1`, начальное состояние 1, 100 Мчип/с, Rectangle, 2 отсчёта/чип, Fs=200 Мвыб/с. Для других установок сохранять их физически обоснованные частоты/полосы и документировать выбранную степень/полином/состояние, а не переносить городские аппаратные параметры автоматически.
- Сохранять код, полином, начальное состояние, Fs, chip rate, pulse, нормировку и тип корреляции в provenance. Gain/clock-fit старого Gold не считать автоматически принятой калибровкой для M.
- Исторические Gold/Weil/Kasami результаты и тесты не удалять и не переименовывать в M. Эти генераторы остаются доступными для воспроизведения истории и явных сравнительных опытов.

Основание: для фактически использованных городских reference N=2047 максимум боковых лепестков периодической АКФ M составляет −66.22 дБ против −29.96 дБ у Gold относительно собственного главного пика. Это результат бесшумного сравнения выбранных кодов при данной обработке, не универсальное преимущество M для всех задач: фазы одной M имеют максимум периодической ВКФ 0 дБ; апериодическая АКФ и доплер требуют отдельной оценки.

Артефакты: `output_data/notes/code_correlations_20261117/{report.html,metrics.json,correlations.npz}`. Точный зондирующий код поставщика WiWorld по этому выбору не установлен; готовый measured CIR повторно кодом не обрабатывать.

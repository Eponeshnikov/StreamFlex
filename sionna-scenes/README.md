# Сцены Sionna RT

| Папка | Соответствие |
| --- | --- |
| `measured/indoor/room_1405_grid_2026-11/` | Шесть моделей для сетки комнаты 1405 после перестановки. Раздельные диапазоны и условия LOS, NLOS и экран. |
| `measured/indoor/room_1405_gscan/` | Сцена RM36 для Г‑скана 2,5 ГГц. Геометрию берёт из источника комнаты 1405 для RT/VNA. |
| `measured/outdoor/wiworld/` | Городская LOD3 для маршрута WiWorld BUPT 3,7 ГГц и варианты геометрии, использованные в исследовании 16 ноября. |
| `standalone/kazan/` | Kazan Center v4 и v4 LOD3. Эти сцены используются в модельных траекториях. |

Сцены креста читает отдельная страница RT/VNA из `output_data/plugins/rt_vna_cross/current/scene_source/`. Каталог использует текущую модель комнаты и её варианты по состояниям и диапазонам. Для Niigata локальной сопоставленной сцены в каталоге нет.

`catalog.json` связывает путь XML, серию измерений и группу в интерфейсе. Для ранее рассчитанных Kazan, WiWorld и Г‑скана выбор продолжает передавать исходный путь, на который завязан кэш. Держите старые ссылки вместе с каноническими папками при переносе этого набора.

Геометрия и материалы переносятся вместе с XML. У замороженной сцены RM36 абсолютные ссылки на меши. При установке под другим путём подготовьте отдельную переносимую копию XML с обновлёнными ссылками перед новым расчётом.
